# Sample documents

Fictional business documents for the demo, the extraction rules, and the tests. Generated by `python -m vaultai.devtools.samples` (run from `backend/`); do not edit by hand. `expected.json` holds the ground truth for each file.

| `demo/invoice_acme_INV-2026-0142.pdf` | Invoice whose printed total ($5,328.00) is not subtotal plus tax ($5,238.00). |
| `demo/invoice_pinecrest_PFS-10388.pdf` | Clean invoice that reconciles; ready for one-click approval. |
